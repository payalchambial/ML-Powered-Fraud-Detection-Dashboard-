ML-Powered Fraud Detection Dashboard

About the Project

ML-Powered Fraud Detection Dashboard is a machine learning project that analyzes transaction data and predicts whether a transaction is potentially fraudulent or legitimate.

Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit

Features

- Transaction data analysis
- Machine learning-based fraud prediction
- Interactive dashboard
- Displays prediction results

Project Structure

Fraud-Detection-Dashboard/
├── app.py
├── model.pkl
├── dataset.csv
├── requirements.txt
└── README.md

Installation and Setup

1. Clone or download this repository.
2. Install the required libraries:

pip install -r requirements.txt

3. Run the Streamlit application:

streamlit run app.py

4. Open the local URL displayed in the terminal.

How It Works

1. Transaction data is provided to the application.
2. The trained machine learning model analyzes the data.
3. The dashboard displays the prediction result.

Objective

To demonstrate how machine learning can help identify potentially fraudulent transactions.
